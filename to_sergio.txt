A-Maze-ing handoff notes
=========================

The project is now in a_maze_ing.py so it runs with:
python3 a_maze_ing.py config.txt

You are free to rename classes and improve the structure. The maze-generation logic
(walls start closed, passages are opened between visited neighbours) should stay the
same unless we agree to change the requested behaviour.

Parser part
-----------
MazeConfig: keeps the already validated configuration values together.
- __init__: receives and stores every setting.
- get_width/get_height: return maze dimensions.
- get_entry/get_exit: return the two coordinate pairs.
- get_output_file: returns where the maze will be saved.
- get_perfect: returns the PERFECT flag.
- get_algorithm/get_seed: return the optional generation settings.

ConfigLoader: reads and validates config files without crashing.
- _load_lines: opens the file and returns its lines or an error message.
- _split_lines: ignores comments/blank lines and checks KEY=VALUE pairs.
- _parse_positive_integer: checks WIDTH and HEIGHT are positive integers.
- _parse_point: changes x,y text into a non-negative coordinate pair.
- _parse_bool: accepts only True or False.
- load_config: combines parsing and boundary checks, then creates MazeConfig.

Maze part
---------
MazeCell: one cell; north/east/south/west are wall bits (1 closed, 0 open).
Its __str__ returns the hexadecimal digit required by the output format.

MazeGenerator: owns the grid and all maze operations.
- __init__: creates a fully walled grid and a seeded random generator.
- get_neighbors: lists valid adjacent cells.
- open_passage: opens both sides of the wall shared by adjacent cells.
- generate_dfs: the recursive depth-first generation already used in the project.
- generate_walk: the existing random-walk-style generation approach.
- generate: selects dfs or walk from ALGORITHM.
- find_path: uses breadth-first search to return a shortest N/E/S/W path.
- save_output: writes hex rows, then blank line, entry, exit, and path.

main validates the command-line argument, loads the config, generates the maze, and
saves it. It returns an exit status instead of allowing exceptions to crash the program.
